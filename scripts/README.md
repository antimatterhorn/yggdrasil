# Scripts

One-off scripts for solving problems of personal interest that don't need the full Yggdrasil simulation stack.

## Contents

| Script | Description |
|---|---|
| [boygirl.py](boygirl.py) | Monte Carlo simulation of the classic "Boy or Girl" probability paradox — explores how conditioning on birth-day or birth-month changes the odds |
| [crossmath.py](crossmath.py) | Brute-force search over permutations to solve a cross-math arithmetic puzzle |
| [gen_texture_atlas.py](gen_texture_atlas.py) | Generates a 1024×1024 RGBA texture atlas of color swatches cycling through hue space |
| [linearApprox.py](linearApprox.py) | Recovers the affine transformation `Ax + b` of a black-box function by probing it with structured inputs |
| [religiosity.py](religiosity.py) | Agent-based demographic simulation of religiosity transmission across generations |
| [sumofcubes.py](sumofcubes.py) | Checks whether consecutive cube sums are perfect squares |
