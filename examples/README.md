# Examples

Illustrative scripts demonstrating Yggdrasil's simulation stack and standalone calculators across a range of physics domains — wave propagation, hydrodynamics, gravity, FEM elasticity, cellular/agent-based models, and pure-math visualizations. Unlike `scripts/`, these are meant to showcase what the framework's `Mesh`/`Physics`/`Integrators`/`Boundaries` layers can do.

## Contents

| Script | Description |
|---|---|
| [bolideAtmosphere.py](bolideAtmosphere.py) | Axisymmetric `(r,z)` Earth atmosphere in hydrostatic equilibrium (`GridHydroKT2d`, `CylindricalRZ` `Grid`, constant downward gravity) out to ~10km, perturbed by a bolide's deposited-energy trail read from an external `(time, altitude, energy)` text file (`bolide.txt`) and sourced into the r=0 column as the clock crosses each entry's timestamp, dumped to Silo |
| [cherenkov.py](cherenkov.py) | 2D scalar wave equation on a grid with a source that accelerates past the wave speed, producing a Cherenkov-like Mach cone wake |
| [complexDiff.py](complexDiff.py) | Complex-valued wave equation (Schrödinger-like) on a grid with two out-of-phase point sources injected into real/imaginary components, bounded by a row of circular Dirichlet obstacles |
| [cosmo.py](cosmo.py) | Runs the standalone `Cosmology` calculator to compute cosmological quantities at a given redshift for a flat ΛCDM universe |
| [diffractionGrating.py](diffractionGrating.py) | Scalar wave equation with a periodic row of circular Dirichlet scatterers acting as a diffraction grating, driven by two coherent point sources |
| [diffractionHydro.py](diffractionHydro.py) | Compressible grid hydrodynamics (HLLC/KT-style) with elevated-pressure source regions diffracting through a Dirichlet obstacle array |
| [doubleSlit.py](doubleSlit.py) | Classic double-slit interference: scalar wave equation with a Dirichlet wall containing two slits, animates the resulting interference pattern |
| [fem_elasticity.py](fem_elasticity.py) | Cantilever beam FEM test — isotropic linear elastic material on a mesh built from `example.obj`, left edge pinned, gravity-like constant force pulls it down, dumps stress/displacement fields to Silo |
| [fireflies.py](fireflies.py) | Kuramoto-style phase coupling on a Poisson-distributed particle cloud (firefly synchronization), animated as a scatter plot with brightness driven by phase |
| [hopfieldMemory.py](hopfieldMemory.py) | Hopfield associative memory network (outer-product weight matrix, asynchronous updates) storing binary bitmap patterns and recalling one from random noise |
| [hornWave.py](hornWave.py) | Scalar wave equation with a Dirichlet dividing wall and a reflecting cone-shaped horn aperture connecting two chambers, illustrating wave focusing/guiding |
| [imageToStringArt.py](imageToStringArt.py) | Runs the `StringArtPy` calculator to approximate an input image as a sequence of straight lines between pins on a circle ("string art"), then plots the result |
| [mandelAnim.py](mandelAnim.py) | Animated infinite zoom into the Mandelbrot set using the `Mandelbrot` calculator, regenerating the grid and escape-time field each frame |
| [mandelbrot.py](mandelbrot.py) | Computes and plots a single smoothed Mandelbrot escape-time image over a specified complex-plane window using the `Mandelbrot` calculator |
| [oort.py](oort.py) | N-body-style gravity: a comet cloud orbiting a central point mass perturbed by a second moving point mass (stellar flyby into the Oort cloud), plots resulting orbits |
| [phase_coupling.py](phase_coupling.py) | Kuramoto phase-coupling oscillators laid out on a structured grid with a bounded search radius, animated as a phase field |
| [plinko.py](plinko.py) | Particle kinetics under constant (gravity-like) force with sphere/box colliders arranged as a Plinko-style pin board, animated as a bouncing scatter plot |
| [reactionDiffusion.py](reactionDiffusion.py) | Three-species reaction-diffusion system (rock-paper-scissors-style cyclic dynamics) on a periodic grid, animated with a three-color colormap |
| [relativity.py](relativity.py) | Runs the standalone `TimeDilation` calculator to compute the velocity and Earth-frame elapsed time for a given proper travel time and distance |
| [tensors.py](tensors.py) | Minimal demo of the `Tensor2d`/`Tensor3d` math API — addition, scalar multiply, determinant, and tensor-vector multiplication |
| [tsunami.py](tsunami.py) | Shallow-water-style scalar wave equation over real bathymetry loaded from a depth map (`sfo.asc`, San Francisco Bay), with an impulsive source and Silo output |
| [ulamSpiral.py](ulamSpiral.py) | Builds an Ulam spiral on a grid via a sieve of Eratosthenes, coloring prime vs. composite cells (with an optional randomized-density mode) |
| [vectors.py](vectors.py) | Minimal demo of the `Vector3d` math API — dot/cross product, addition, scalar multiply, magnitude, normalization |
| [voronoi_diag.py](voronoi_diag.py) | Builds a `VoronoiMesh2d` from node positions generated by any of several point-distribution generators (random, Fibonacci, Poisson, CVT, HCP, glass, lattice, tanh) and plots cells colored by area |
| [waveLogo.py](waveLogo.py) | Scalar wave equation with a maze of Dirichlet boxes tracing out the "Yggdrasil" logo/wordmark, driven by multiple damped-harmonic-oscillator point sources ("speakers") |
| [yggdrasil.py](yggdrasil.py) | Bootstrap module that adds the build directories to `sys.path` and re-exports the core C++ bindings (`DataBase`, `State`, `Integrators`, `Controller`, `IO`, etc.); imported by every other example as `from yggdrasil import *` |

## Assets

Non-script data files consumed by the scripts above: `example.obj` (mesh geometry for `fem_elasticity.py`), `sfo.asc` (bathymetry depth map for `tsunami.py`), `bolide.txt` (sample energy-deposition trail for `bolideAtmosphere.py`), and `pi.png` (default input image for `imageToStringArt.py`). `einstein.jpg`, `lincoln.jpg`, `logo_test.png`, and `logo.xlsx` are additional sample/scratch assets not directly referenced by any script but usable as alternate `filename` input to `imageToStringArt.py` (image files only).
